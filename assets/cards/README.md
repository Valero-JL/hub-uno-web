# Cartas (assets)

Coloca aquí las imágenes de cada carta + el reverso.

Convención de nombres (minúsculas):

- Numéricas: `red-0.png` … `blue-9.png`
- Acciones: `red-reverse.png`, `red-skip.png`, `red-draw2.png` (y yellow/green/blue)
- Comodines: `wild.png`, `wild-draw4.png`
- Reverso: `back.png`

La extensión se configura en un solo lugar: `CARD_IMAGE_EXT` en `js/constants.js`.

Este repo incluye SVG de relleno para que el juego sea jugable de inmediato. Sustitúyelos por el arte final cuando esté listo.

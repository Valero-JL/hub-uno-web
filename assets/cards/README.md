# Cartas (assets)

Imágenes finales del mazo HUB-UNO (PNG optimizados para web).

Convención de nombres:

- Numéricas: `red-0.png` … `blue-9.png`
- Acciones: `red-reverse.png`, `red-skip.png`, `red-draw2.png` (y yellow/green/blue)
- Comodines: `wild.png`, `wild-draw4.png`
- Reverso: `back.png`

La extensión se configura en `CARD_IMAGE_EXT` dentro de `js/constants.js`.
